# 园区与月台管理 YMS企业能力说明

> 上海如静知华信息科技有限公司 · [知华科技官网](https://www.zhuatech.cn/)

## 业务覆盖

本项目实现 0 个关联模块：。所有模块接入统一的业务台账、状态机、责任期限、风险标记、审计和控制中心。

## 领域控制

核心规则：预约时窗、月台可用性、车辆资质与作业容量联合校验。

领域接口：`POST /api/enterprise/yms/evaluate-slot`。接口返回可解释的指标、阻断项和决策结果；不会在客户端绕过关键业务校验。

## 控制闭环

```text
草稿 → 经办提交 → 管理员复核 → 登记凭证摘要 → 业务办结 → 外部适配器回执
```

已实现：

- 组织代码、业务期间、控制类型、责任人、风险等级和到期日；
- 幂等键与业务编号唯一性；
- 经办/管理员职责分离；
- SHA-256 附件摘要与办结凭证门槛；
- 乐观锁、外部回执状态、逾期及多维汇总；
- 创建、修改、流程、审批、附件、办结、同步和设置的审计链；
- 生产 profile 默认口令、数据库口令和跨域来源安全门禁。

## 集成边界

预留 WMS、TMS、地磅、车牌识别与叫号屏 的适配器边界。社区源码不内置生产令牌、CA 私钥、短信密钥或企业真实数据；接入时应使用环境变量或企业密钥管理服务。

## 生产验收基线

1. 修改全部默认密码，限制 `ALLOWED_ORIGINS`，启用 `SPRING_PROFILES_ACTIVE=prod`。
2. 由企业数据库变更流程管理表结构与备份恢复。
3. 由对象存储承载附件实体，应用只保留摘要和存储键。
4. 将审计日志接入集中日志/SIEM，并设置保留策略。
5. 执行后端测试、前端生产构建、Compose 校验和安全扫描。
